# 架构设计与优化方法

## 1 目标不是最大化一个硬件数字

把优化问题写为：在工作语义与质量约束下，选择架构 x、映射 m、运行策略 p，使端到端指标 f(x,m,p) 更好。约束包含容量、面积、功率、热、互连、支持操作和软件可实现性。成本依据 c 与输入分布 w 是条件，不能在比较时无记录地变化。

多目标用 Pareto 非支配集呈现：一个方案若在所有比较目标上不差且至少一项更好，则支配另一个方案。不可行或功能错误的方案先移出可选集。排序依赖不确定参数时报告条件区间，而非单一冠军。

## 2 从瓶颈假设到候选

| 瓶颈证据 | 候选改动 | 必须同时检查的代价 |
| --- | --- | --- |
| 计算资源饱和且数据供给充足 | 更多 PE/SM/阵列、频率或更低精度 | 供给带宽、面积、功耗和质量 |
| 重复搬运或容量溢出 | 切块、融合、局部存储、压缩 | 活跃内存、解码、并行度和外溢 |
| 端口/ADC 争用 | bank/端口/ADC 数或重新调度 | 外围面积、能量、布线与校准 |
| D2D/PCIe/NIC 热点 | 数据放置、路径、分层通信 | 其他割集、同步和迁移成本 |
| 小任务开销主导 | 批处理、融合、通信合并 | 尾延迟、内存和可重叠性 |
| 负载不均或 straggler | 重分片、动态策略、专家放置 | 调度成本、跨域数据和公平性 |
| 热限制降低频率 | 几何/功率分配、时分执行、散热条件 | 时延、面积、成本与误差模型 |

“更大缓存、更宽带宽、更多层”不是完整优化说明。每个候选都要说明减少哪条数据移动、缩短哪段临界路径或解除哪个容量限制，以及新增了哪些需求。

## 3 设计空间的组织

先确定离散结构：资源类型、封装组织、存储层级、网络拓扑；再选规模与精度；再搜索切块、放置和策略。结构不同的候选可以拥有不同参数集合，不能强制塞进同一个固定笛卡尔积。

把模板约束、物理可行域和派生关系用于提前过滤。比如增加 Die 数同时改变 D2D、容量和热几何；ADC 数不能超过布局/连接能力；HBF 的带宽、粒度和接口应来自同一规格条件。

## 4 搜索方法的适用范围

| 方法 | 适合问题 | 限制 |
| --- | --- | --- |
| 枚举/网格 | 小规模离散空间、需要完整覆盖 | 维度增长快，先约束过滤 |
| 随机/拉丁超立方 | 初期采样连续或混合参数 | 不保证最优，需重复与覆盖说明 |
| 分层/启发式 | 结构—映射耦合、规模较大 | 容易错过跨层交互收益 |
| ILP / CP-SAT | 可表达的容量/放置/调度约束 | 非线性物理成本需近似或外循环 |
| 贝叶斯/代理优化 | 单次评估昂贵、变量维度适中 | 外推、离散切换和约束需处理 |
| 多目标进化搜索 | 不连续、多目标与复杂结构 | 预算高、结果依赖编码和种子 |

避免在不可靠的目标函数上运行更复杂的搜索。先检查基线和可手算点，再让优化器探索；以同样预算比较搜索策略，保留失败和不可行候选。

## 5 多层模型控制成本

解析上下界筛掉明显不可行/被支配候选 → 事件模型验证资源竞争 → 对排名敏感的候选细化微架构/热模型 → 用实测或外部工具校准关键参数。若粗模型误差可能改变排序，不依据单点估计过早剪枝。

可以对校准数据训练代理模型，但要保存训练范围、预测误差和域外标志。新拓扑或新计算机制通常不能直接继承旧模型精度。保留高保真预算给决策最敏感的候选。

## 6 三种收益要拆开

架构收益：固定映射和语义，改变资源或成本。映射收益：固定硬件，改变切块/放置/调度。协同收益：二者一起重新优化。对照实验分别列出，避免把更好的编译策略全部归功于新增硬件。

精度/算法收益另外报告质量变化。CIM 的乘加能量优势只有在转换、写入、移动、调度和质量代价之后仍存在，才是端到端优势。3D 的通信距离优势也可能被垂直通道或散热限制抵消。

## 7 停止条件与推荐结论

停止可依据预算、Pareto 集稳定性、目标达成或新增实验信息价值下降；不能声称有限搜索证明全局最优。最终推荐包含适用负载/精度、参数范围、约束余量、主要瓶颈、误差与下一步需验证项。

最有价值的下一次实验通常是能消除关键不确定性的实验：例如验证 ADC 服务率、HBF 真实访问粒度、双 Die 远端成本或 NIC 共享行为。第一性原理决定该测什么，搜索算法决定怎样高效比较已定义的候选。
