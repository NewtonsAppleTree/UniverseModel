# 参数、依赖与数学方法

## 1 先分清参数的身份

| 类型 | 英文 | 获取方式 | 处理方式 |
| --- | --- | --- | --- |
| 任务参数 | Workload Parameter | 真实图、profile、数据分布 | 固定比较口径或分组报告 |
| 架构决策量 | Design Variable | 设计者选择、约束求解 | 可修改/搜索，必须检查可实现性 |
| 实现/器件参数 | Characterization Parameter | 手册、测量、工具、论文 | 记录来源与工艺/电压/温度等条件 |
| 派生量 | Derived Quantity | 明确公式和输入 | 不与原生量独立编辑 |
| 策略参数 | Policy Parameter | 编译/runtime 决策 | 保存策略版本和适用阶段 |
| 校准量 | Calibrated Parameter | 观测数据拟合 | 保存残差、适用域和独立验证 |
| 观测指标 | Observed Metric | 计数器、输出和事件 | 带单位、边界、时间区间 |

参数依赖示例：精度 → 编码/位切片 → 有效容量与转换阶段 → 数据流量/资源需求 → 排队与延迟 → 动作能量/温度 → 频率或错误率反馈。它不是所有量一次前向求值的 DAG：温度与功率等动态反馈必须放入时间模型或显式迭代求解，不能藏成循环派生字段。

本目录公式用于条件推导、数量级检查和解析筛选，不表示已实现模型。默认容量单位 byte、时间 second、带宽 byte/second；MAC 与 FLOP 的换算按明确约定。每个公式都应绑定版本、输入来源和应用范围。

## 2 容量、计算与带宽

### M01 物理容量与逻辑数据大小

同质阵列的原始物理位数：`C_raw_bits = N_array × N_row × N_col × N_layer × bits_per_cell`。只有各层具有同样组织时才可相乘；异构阵列应求和。

未压缩张量数据大小：`D = ceil(N_element × bits_per_element / 8)` byte。实际分配还包含对齐、分块 padding、ECC/校验、元数据和副本；压缩格式需明确块粒度及索引开销。原始容量、用户可用容量、有效权重容量分别报告。

### M02 CIM 的有效权重容量

若每个 cell 承载 q 个权重位、权重精度 b_w，则位切片数 `s = ceil(b_w / q)`。若差分/符号表示平均需要 d 组 cell，且物理可用比例为 u，则近似容量上界为 `N_weight ≤ floor(N_cell × u / (s × d))`。

该式仅用于指定编码下的数量级上界；块形状、行列映射、备份、坏单元、校准和符号处理可能进一步降低容量。d 不固定等于 2；数字与模拟实现分别声明编码。容量增加不等于所有 cell 可同周期激活。

### M03 计算量与峰值吞吐

稠密 GEMM：`W_MAC = M × N × K`。同质资源峰值：`P_MAC = N_engine × MAC_per_cycle_per_engine × frequency`。异构资源只在相同操作/精度、可同时工作时求和；不把 CPU 指令数、GPU FLOP 与 CIM analog operations 直接相加。

理想计算下界为 `T_compute ≥ W_MAC / P_MAC`。映射空洞、边界 padding、稀疏索引、输入供给和累加开销需另外建模。若采用 1 MAC = 2 operations，TOPS 口径在所有对比中一致。

### M04 有效带宽与单次传输

若 r 为每 lane 原始 bit/s，`B_eff = lanes × r × η / 8`，η 是该层尚未扣除的编码/协议效率。若引用规格已是有效 payload 速率，不再次乘相同效率。

孤立、单路径、串行化摘要可用 `T_transfer ≈ L_start + D / B_eff`。多跳路径取决于 store-and-forward、cut-through、分块流水和共享端口，不能把每跳 `D/B` 都机械相加。链路带宽是容量；流实际获得的带宽由并发和仲裁决定。

### M05 Roofline 与算术强度

在选定存储边界上，`I = W / D_boundary`，`P_attainable ≤ min(P_peak, B_boundary × I)`。多个瓶颈层级可分别计算上界并取最紧约束。

D_boundary 是该映射经过该接口的实际字节量，不是输入文件大小。Roofline 是可达性能上界，忽略的串行、启动和不规则开销只会降低实际性能；不能用它证明精确延迟。

## 3 因果、队列与存储

### M06 临界路径与资源下界

对于给定计划，在独立有效下界都成立时：`T ≥ max(T_critical_path, max_r(Q_r / C_r), max_cut(D_cut / B_cut))`。Q_r 是资源服务需求，例如 lane-cycle、port-byte 或 slot-second；C_r 使用匹配单位。割集流量必须确实跨越该割集。

临界路径只累计因果串行的必要阶段，资源下界反映争用总需求。它们是下界，不能简单求和。计算和搬运完全串行时近似相加；完全可重叠且没有额外瓶颈时才可近似取最大值；一般情况由事件模型决定。

### M07 有限服务与 Little 定律

单服务资源接收请求 i 的简化模型：`start_i = max(ready_i, free_time)`，`finish_i = start_i + service_i`。流水线需分别描述 latency、initiation interval 与各阶段 occupancy，不能把 finish_i 当成下一次最早发射时刻。

稳定、长期且边界一致的排队系统满足 `L = λ × W`，L 是平均在系统内请求数、λ 是有效到达/离开率、W 是平均逗留时间。单服务站 `ρ = λ × E[S]`；无限缓冲稳定性通常要求 ρ < 1，多服务站还需明确并行能力与策略。

Little 定律不预测具体等待分布，也不能直接用于短暂启动阶段。有限缓冲丢弃或背压时用实际接纳率，并分清队列等待与总逗留时间。高负载下均值不足以说明尾延迟。

### M08 CIM 阶段与外围共享

先根据编码生成实际阶段图：input encode → array evaluate → convert → shift/accumulate。对需要依次进行的输入 bit phase，`T ≥ Σ_phase T_phase`；若位切片阵列并行，不再把它们作为串行倍数。

某 phase 需要 n_conv 次转换，拥有 n_ADC 个同质 ADC，每个发射间隔 II_ADC、流水线延迟 L_ADC，且输入同时就绪时，理想完成时间近似为 `L_ADC + (ceil(n_conv/n_ADC) - 1) × II_ADC`（n_conv > 0）。只有非流水 ADC 才能直接用批数乘单次转换时间。

实际还受列复用、sample-and-hold、阵列重算、输出位宽、累加和共享总线限制。ADC 分辨率、采样速度与能量必须带实现条件。3D 层若共享转换器或垂直链路，增加层数只增加容量而未必增加有效吞吐。

### M09 活跃内存与缓冲

`M_peak = max_t Σ_{a live at t} allocated_bytes(a)`，在每个物理存储资源上单独求值。合法别名的同一物理区域只计一次；不同存储上的副本分别计入；双缓冲、prefetch、通信工作区和碎片均需覆盖。

静态生命周期给出保守上界，动态调度可能改变重叠。只要求单个 tile fit 不足以证明双缓冲流水或多 stream 的总容量合法。

### M10 数值范围与累加

对 K 项乘积和，可先使用 `abs(sum) ≤ K × max_abs(a) × max_abs(w)` 推导范围，再选择覆盖该范围的有符号累加位宽。常见保守估计 `b_acc ≈ b_a + b_w + ceil(log2 K)` 需结合有符号编码、缩放和边界核对。

量化误差、ADC 饱和与算法误差可能相关；输出噪声不能无条件按独立方差相加。定点规则包含缩放、舍入和饱和；浮点规约顺序变化也可能改变结果。

## 4 能量、面积、通信与热

### M11 能量与功率

`E_total = Σ_action(count_action × e_action) + ∫ P_leak(state,V,T) dt`。使用动态能量表时再加泄漏；若来源是含静态能量的测量总能量，先对齐边界，避免重复。

`P_avg = E_total / T_window` 仅是所选区间平均功率。峰值供电与热热点需要时间/空间信息。CIM 包含编程、ADC/DAC、数字外围、buffer 与搬运；系统比较还需明确是否包括 CPU、HBM/HBF、NIC、交换机和冷却。

### M12 硅面积与封装占地

`A_silicon = Σ_unique_die A_die`，每个物理 Die 只累计一次。`A_package_footprint` 由几何投影、间距、interposer、I/O 和结构决定，不能用 A_silicon 代替。

堆叠能缩小投影占地，但增加裸片数量、互连/封装成本及散热难度。早期面积模型可组合阵列、外围、存储和控制，但互连/布线余量需明确。若研究经济性，再加入良率、测试和组装损失，不以面积直接等同成本。

### M13 Ring AllReduce 的条件基线

对 p > 1 个同质参与者、每个参与者同样的 n byte 数据，标准 reduce-scatter + allgather ring 理想估计为 `T ≈ 2(p-1)α + 2(p-1)n/(pB)`。α 是每步启动成本，B 是该 ring 的有效瓶颈带宽。

该式假设分片均匀、路径可并行、无额外拥塞，且规约计算可忽略或已隐藏。若规约不被隐藏，加入按实际算法位置计算的代价。它不是所有 collective 的通式；异构、多层拓扑、小消息、协议切换和共享 NIC 需实际展开。

### M14 热 RC 与反馈

多节点集总模型可写为 `C_th · dθ/dt = P(t) - G_th · (θ - θ_ambient)`，C_th 单位 J/K，G_th 单位 W/K；稳态满足 `G_th · (θ-θ_ambient) = P`，前提是有合理的散热边界与稳定解。

热模式分 off、budget、RC。budget 只检查功率/密度预算，不能输出可信温度；RC 需要几何、材料/界面与校准。3D 堆叠通过热耦合矩阵表达，不用 die_count 倍增一个温升常数。

温度影响泄漏、频率限制或器件误差时，使用时间步进或带收敛判据的耦合迭代；声明步长与稳定性。未经校准的 RC 只是趋势模型，不能承担热签核。

## 5 扩展、质量与不确定性

### M15 扩展与串行比例

同构强扩展在工作量固定时：`S(p)=T(1)/T(p)`，`Efficiency=S(p)/p`。弱扩展随资源增加保持每资源工作量近似不变，常用 `T(1)/T_weak(p)`，但需说明质量与问题规模的变化。

Amdahl 基线：`S(p) ≤ 1/(s+(1-s)/p)`，s 是固定的串行比例且忽略额外通信；实际系统中通信、负载不均衡及容量变化会改变这一假设。异构资源不能用设备数直接归一化，可报告功耗/成本归一收益或明确的能力等价量。

### M16 功能误差与质量约束

浮点常用逐元素 `abs(y-y_ref) ≤ atol + rtol×abs(y_ref)`；任务还可报告 RMSE、最大误差、准确率或 perplexity 等指标。近零参考值使纯相对误差失效。NaN/Inf 处理和容差在实验前声明。

CIM 随机误差需多次采样并报告分布；硬件误差与训练/量化补偿策略一同版本化。不同质量条件下的速度不可直接排名。

### M17 敏感性与不确定性

连续正参数局部敏感度可写为 `S_i = (x_i/y)·∂y/∂x_i`，数值差分注明步长。整数结构、阈值切换、不可行点和重新映射会使曲线不光滑，应使用分组对比或有限差分情景。

固定映射差分用于归因，重新映射差分包含编译器响应。Monte Carlo、区间分析或情景分析应保留参数相关性；局部一阶近似不能覆盖强非线性。参数不确定性与随机重复波动分开报告。结论对哪个未知量最敏感，就优先测量或校准哪个量。

## 6 参数依据与验证优先级

先从目标负载获取工作量与访问需求，再从规格获取结构上限，从基准测量或事件模型获取持续行为，从电路/存储/系统工具取得局部成本，最后用独立数据校准。每条来源记录文档版本、页/表/链接、工作条件、转换步骤和适用范围。

公开典型结构可参考 NVDLA 的计算/存储数据通路、Timeloop/ZigZag 的映射空间、Accelergy 的动作成本、CACTI 的存储结构、NeuroSim 的 CIM 外围、Ramulator 的存储时序。它们回答不同问题，组合前必须统一口径。资料链接见[结构参数手册](../architecture/architecture_parameters.md)与[异构规划](../architecture/heterogeneous_cluster_plan.md)。

没有数据时保留符号和范围，先找出结论是否依赖它；若排序对某个未知参数不敏感，可以继续粗模型探索。若高度敏感，则补充依据比增加模型细节更有价值。
