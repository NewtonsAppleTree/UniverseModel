# 实验产物、来源与复现

## 1 保存的最小证据链

一个结果必须能够回答：运行了什么输入，使用哪套参数和代码，采用什么映射及成本依据，执行是否完整，误差和指标怎样计算。`run_id` 标识一次尝试；内容哈希标识相同输入；两者用途不同。复现生成新 run，并通过 `reproduces_run_id` 引用原运行。

建议运行目录为 `data/runs/<run_id>/`，以下是规范设计，当前尚未实现写入器。

| 产物 | 内容 | 语义负责方 |
| --- | --- | --- |
| manifest.json | 状态、时间、代码/环境、种子、所有产物哈希与依赖 | artifacts，evaluation 发起状态变更 |
| config/resolved.json | 完整有效参数、单位、覆盖来源、派生公式版本 | configuration |
| workload/spec.json | 图、数值规则、输入清单和工作负载版本 | workloads |
| hardware/spec.json | 实例、能力、关系和装配版本 | 硬件模型 |
| plans/ | 放置、执行与通信计划，格式与哈希 | compiler；动态增量来自 runtime |
| models/manifest.json | 组件实现、精度、成本表、校准与误差版本 | costmodel / 硬件模型 |
| results/metrics.json | 值、单位、范围、计数器与计算公式版本 | simulator / evaluation |
| results/validation.json | 参考、误差、容差、通过项与失败项 | evaluation |
| outputs/ | 结果引用或内容、数据版本与校验值 | 组件产出，artifacts 保存 |
| diagnostics/、trace/ | 错误、策略决策、可选轨迹与采样声明 | runtime / simulator |

语义负责方生成内容，artifacts 负责一致序列化和写入。大文件可放外部对象存储，但清单需记录可定位 URI、内容哈希、大小、访问/保留约定；易过期 URL 不能作为唯一复现依据。小型、可公开的输入样例可进入 Git；大数据和日常实验结果不进入源码仓库。

## 2 写入与故障恢复

运行状态为 `preparing → running → succeeded/failed/cancelled`。先建立准备清单，验证冻结输入，再进入运行。单文件采用临时文件、校验后替换或存储系统等价机制；所有必需产物持久化并核验后，最后写完成清单。这里的承诺是单产物与提交标记，不是假定整个目录原子更新。

中断留下的 preparing/running 记录不能算成功；恢复工具应识别缺失产物并标为 incomplete 或创建失败诊断。历史成功运行的核心产物不可原地修改；重新分析生成带来源引用的新分析产物。内容去重可以复用 blob，但删除需考虑其他 run 的引用。

## 3 哈希与版本身份

结构数据先规范化再哈希：固定字符编码和 schema 版本、排序对象键、保留有语义的数组顺序、明确数值表达、统一单位；NaN/Infinity 采用 schema 规定的显式表示或拒绝。源码文件和二进制数据按原始字节哈希。不能把对象键的随机顺序、显示单位或绝对机器路径混进语义身份。

保存规范化版本、原始配置、已解析配置、源码 commit 和 dirty 状态。有未提交修改时保存补丁及新增文件或完整可恢复源码归档；依赖包版本、模型插件版本、外部工具版本及随机种子分别记录。种子相同不保证跨算法版本逐位一致。

哈希匹配证明拿到同一份内容；正确性仍需 schema、约束和独立参考验证。模型升级导致语义变化时更换版本，不能只更新成本数值而保留旧身份。

## 4 三类重用

| 操作 | 所需记录 | 重新执行范围 |
| --- | --- | --- |
| 重现实验 Replay | 输入、冻结配置、计划、代码与模型版本 | 重新装配并执行，生成新 run |
| 重新分析 Reanalysis | 原始计数器/输出、指标定义版本 | 不执行模型，只产生新分析结果 |
| 恢复执行 Resume | 完整检查点、事件队列、组件/runtime 状态、随机状态 | 从检查点继续，需严格实现兼容 |

普通输出文件不是执行检查点。snapshots 只有在覆盖全部有状态参与者、待处理事件和稳定时间边界后，才具备恢复意义。第一阶段优先支持 Replay 和 Reanalysis，Resume 独立验收。

## 5 保留、观察与复现成本

核心汇总计数器不依赖 trace，关闭轨迹不改变执行结果。采样必须记录规则和覆盖率，不能从部分轨迹冒充精确总量；随机采样使用独立随机源，不能干扰模拟误差模型。失败运行保留已冻结输入、终止原因和最后有效统计区间。

实验规模扩大后可分层保留：全部候选保留 manifest/配置/指标，代表候选保留详细输出，异常和瓶颈候选保留完整轨迹；删除策略显式标记哪些分析或复现能力随之丢失。
