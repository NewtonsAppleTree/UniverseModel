# 所有模块的模型代码与文档规则

这是一项全仓库约定，不限于 ADC。先对 chipmodel 的全部目录和 Python 定义执行；其他主模块首次实现或修改时采用同一规则。规则约束表达与验证方式，不要求所有 Unit 具有相同硬件机制。

## 从系统关系到代码

先确定研究问题与边界，再列出资源、连接、操作、参数来源和结果范围。区分四种图：包含/所有权树、允许有环的物理连接图、公式依赖 DAG、一次任务的操作依赖 DAG。目录不是硬件实例；组合不是额外的免费算力；时序不能直接由函数调用顺序推定。

每个模块说明它拥有哪些状态、只引用哪些外部资源，以及和相邻模块交换什么量。例如 array 输出 A，经显式跨阻变换成为 V，才可输入电压 ADC；DDR 数据率是 transfer/s，不能当作时钟 Hz 再乘两次 DDR 系数。

## 定义前与字段旁的注释

每个 class/def 前写 1–3 行用途注释。有公式时定义物理量及关系；长推导放 UNITS.md。无数值公式的构造、注册、连接验证等说明不变量或状态变化即可。装饰器紧接前置注释，docstring 可补充假设、输入输出和错误。

```python
# 描述一条时钟域；Tclk = 1/f，cycle 数只在同一域内比较。
@dataclass(frozen=True, slots=True, kw_only=True)
class ClockDomain:
    domain_id: str  # Clock-domain identity；无量纲标识。
    frequency_hz: float  # 固定频率 f [Hz]；不是 DDR 有效数据率。

    # 推导周期 Tclk = 1/f [s]；频率必须为正。
    @property
    def period_s(self) -> float:
        return 1.0 / self.frequency_hz
```

字段行尾写专业含义、单位、必要边界；派生字段再写关系式。`lane`、`request`、`sample`、`MAC`、`byte` 不能统称数量；布尔/枚举写成立条件或语义。函数参数的意义与单位写在前置注释、签名旁或同模块接口表中；不要为 self 等语言参数写无意义说明。

## 每个模块的 UNITS.md

模块目录包括主模块、子系统、已有的细分目录。每个目录都提供自己的说明；父目录负责关系与导航，细分目录负责参数和行为，不复制整套字段。文档最少包含：

| 内容 | 必需信息 |
| --- | --- |
| 模块职责与边界 | 拥有/引用的资源；不覆盖的行为；对上下游的要求 |
| Unit 清单 | 专业名称、模型 ID 或实现位置、参数模型/功能/时序的覆盖层次 |
| 参数字典 | 字段、专业术语、单位、输入/派生/状态、范围、关系与来源 |
| 关键参数 | 对延迟、吞吐、容量、通信量、误差或功率最敏感的量及作用条件 |
| 接口与顺序 | 参数 → 校验/推导 → 独立查询或功能计算 → 结果；状态变化另行声明 |
| 公式与验证 | 量纲、假设、舍入/边界、独立手算或数值参考、物理校准依据 |

纯容器和软件基础设施明确“无独立物理计量”，列身份、引用和约束。没有实现的候选 Unit 保留名称、关键量与设计位置，并明确未实现，不用空类冒充覆盖。

## 参数与计算约束

设计输入必须显式给出或引用有依据的 profile；确定性派生量只读。时钟、吞吐、容量、编码与技术时序分别建模，防止相互矛盾的冗余输入。SI 后缀与 bit/byte、十进制/二进制单位明确，cycle 绑定时钟域。

计数排除 bool/非整数；验证有限数、范围、整除、输入 shape、编码与下溢/溢出。类冻结不等于嵌套数据冻结；使用 tuple 或明确所有权。物理时延/能量从特征化得到，分析模型必须列出无争用、供数、保持、刷新等假设。

`derive/estimate` 不偷偷修改硬件状态。`evaluate` 声明功能语义。事件仿真另行处理 accepted、源消费、目的可见、背压、取消、复位、同 tick 顺序与排空。host wall time 不能进入目标性能指标。

## 还需要考虑的系统问题

| 问题 | 设计要求 |
| --- | --- |
| 资源身份与唯一计量 | 每个物理实例唯一归属；摘要成本与内部成本互斥；同一资源的多次真实操作允许分别计量 |
| 数据语义 | 量纲、符号、shape、layout、地址范围、版本、别名和可见性明确 |
| 时间与因果 | 多时钟域先换成 second；依赖下界、资源工作量下界与真实调度完成时间分开 |
| 输入相关成本 | 稀疏、饱和、行命中、路由和写放大不能只靠一个全局利用率 |
| 数值与不确定性 | nominal precision 与 ENOB 分开；误差、PVT 与来源适用域可追溯 |
| 所有权与有限容量 | source lease、输出容量、在途数、共享端口与重试身份有协议 |
| 隔离与复现 | 冻结配置、独立状态、按用途划分随机流；版本和初态参与实验身份 |
| 配置与缓存 | 更新依赖触发重算与验证；不要只按文件名缓存结果 |
| 观测与计费 | 读指标/开启 trace 不改变执行；性能计数器自身开销单独建模 |
| 验证与性能 | 使用独立参考、守恒与边界反例；优化热点仍保持语义和因果 |
| 扩展与兼容 | 小接口、显式能力、版本化；不把内部对象布局当跨语言 ABI |
| 快照与终止 | 事件、组件、数据、随机和外部模型一起恢复；窗口结束不等于任务完成 |
