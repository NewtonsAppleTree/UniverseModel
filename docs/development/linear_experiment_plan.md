# 首个线性算子实验：开发计划与验收

日期：2026-11-20。依据[使命](../../PROJECT_MISSION.md)、[研究路线](../RESEARCH_ROADMAP.md)与[软件调研](../reference/ai_software_corpus_review.md)。

## 目标与范围

在相同输入和硬件参数下，对比 GEMM `A[M,K] B[K,N] = C[M,N]` 的输出驻留与部分和回写方案，回答分块怎样改变容量合法性、搬运量和资源时间下界。MatVec 使用 `N=1` 的同一语义。组件可独立调用；这是一项平台验证实验。

首版支持正整数 M/N/K、行主序稠密张量、INT8 输入/INT64 累加输出及 binary64 输入/累加输出。无 bias、转置、稀疏跳零、量化 scale 或 FMA；这些属于后续显式扩展。INT8 使用保守范围保证所有部分累加均可在 INT64 中表示。浮点使用独立有理数参考及显式容差验证。

## 执行顺序

| 批次 | 工作 | 验收 |
| --- | --- | --- |
| A | 只含实际使用字段的公共任务/计划值；workloads 输入生成、工作量、独立参考 | 矩形、MatVec、数值边界、可复现身份和错误输入测试 |
| B | compiler 生成显式 tile 序列、独立检查覆盖/归约顺序、三块缓冲规划与解释执行 | 非整除尾块正确；缺失/重复/越界/错序计划及容量不足被拒绝 |
| C | evaluation 复用 MAC/DMA 模型与 run/artifact，保存成功与失败候选 | 两方案输出一致，流量差异可手算；目标时间与宿主时间分开；能耗未知 |
| D | 示例、JSON 配置、模块 UNITS、来源/限制、CI 与 STATUS | 必需检查、业务测试、独立示例、产物回读和 wheel 构建通过 |

映射固定三个紧密打包的 scratch buffer，A/B 每步重新载入。输出驻留方案在处理同一输出 tile 的全部 K 切片期间保留 C；另一方案每个 K 切片后写回 C，下个切片前再读。外部 row-major 子矩形按逐行 DMA 请求计量；不假定整个子矩形物理连续。

资源分析使用声明精度下的 MAC 服务参数及一条串行 DMA 通道。统计各自服务需求并给出乐观资源下界；不冒充事件时序、真实设备性能或系统能耗。首版不新增运行时/事件引擎。

## 后续

通过本次验收后，补 Linear 前向/反向/更新和短算子链；以实际问题选择 PyTorch、Timeloop/ZigZag 等外部验证案例。首版正确性不依赖大型外部框架安装；外部工具的性能交叉验证与物理校准仍单独记录。
