# 验证方法与阶段门槛

## 1 验证对象与适用精度

| 模型层次 | 必须证明什么 | 不能据此宣称什么 |
| --- | --- | --- |
| 结构模型 | 引用、单位、层级、容量与组合约束合法 | 功能正确或性能准确 |
| 功能模型 | 计算、数据版本、同步与数值误差符合约定 | 有可靠时序或能耗 |
| 解析模型 | 工作量、流量、资源界与公式假设一致 | 实际争用、队列与重叠已还原 |
| 事件模型 | 因果、有限资源、争用与重叠正确 | 已有逐周期或电路精度 |
| 逐周期模型 | 关键流水线、端口与仲裁逐周期一致 | 已完成物理实现或热签核 |

每份结果声明覆盖的行为、简化项、校准范围与误差。混合精度可以按资源选择，但同一工作不能同时由摘要模型和细节模型重复计时、计流量或计能量。

## 2 验证所有者

| 位置 | 重点 | 代表性证据 |
| --- | --- | --- |
| tests/contracts、configuration | 契约、配置解释和迁移 | 错误单位、悬空引用、覆盖来源、约束失败 |
| tests/costmodel | 成本适用域与单位 | 校准点、插值范围、外推拒绝或标识 |
| tests/chipmodel | 组件状态与资源 | 容量、端口冲突、流水线、CIM 位映射 |
| tests/systemmodel、clustermodel | 系统与共享路径 | DMA/NIC 上限、NUMA、链路争用和通信匹配 |
| compiler/tests | 编译转换与映射 | 独立语义比对、生命周期和容量证明 |
| tests/runtime、simulator | 策略、因果和终止 | 背压、并发完成、稳定排序、死锁与复位 |
| tests/workloads、integration | 参考与完整链条 | 输入有效性、输出误差、手算时间和复现 |
| tests/artifacts、evaluation、ui | 证据与使用流程 | 中断状态、缺失产物、比较口径、配置往返 |

目录表示验证归属，当前尚无这些模块的执行测试。现有 tools/check_structure.py 只检查骨架、文档、依赖图和结构示例，不能替代上表的实现验收。

## 3 不随实现变化的检查

资源容量不能为负或超售；数据没有凭空产生、消失或提前可见；任何开始事件都满足依赖；时间单调；每个请求至多完成一次；能量和流量在明确边界内只累计一次。地址复用必须有生命周期依据，逻辑设备视图不能增加物理资源数量。

整数参考按位宽、饱和、溢出规则比较；浮点采用预先规定的绝对/相对容差，并明确 NaN、无穷和有符号零处理。随机 CIM 误差还需报告输出分布和任务质量，不能仅运行一次并报告通过。

时序先验证单次计算、单次传输、竞争同一资源、流水线连续请求和计算/传输重叠；再验证双 Die、共享 PCIe/NIC 和集群通信。每个案例保存初始状态、可手算预期和偏差解释。

## 4 公平指标与边界

| 指标 | 定义 | 必须声明 |
| --- | --- | --- |
| 任务延迟 Latency | 约定终点减起点 | 输入装载、预处理、写回和通信是否计入 |
| 持续吞吐 Throughput | 测量区间内完成工作量 / 时间 | 工作单位、预热、负载与批量 |
| 资源利用率 Utilization | 已占用槽位时间 / 可用槽位时间 | 槽容量、有效频率和测量区间 |
| 存储峰值 Peak Live Bytes | 同时活跃分配的最大字节数 | 层级、别名、双缓冲和元数据 |
| 接口流量 Traffic | 指定边界通过的实际字节 | 方向、协议开销、重传与多跳口径 |
| 能量/面积 Energy/Area | 按所声明范围累计 | 芯片/封装/节点边界，泄漏与外围覆盖 |
| 扩展效率 Scaling Efficiency | 同一基准下的加速 / 资源倍率 | 强/弱扩展，异构资源归一化方式 |

忙碌时间比例不等于多槽利用率；多个操作的等待区间不能直接求和作为端到端延迟。延迟分位数要有足够样本与请求到达模型。峰值 TOPS、有效 MAC/s、目标仿真时间和宿主程序运行时间分开记录。

## 5 实验与校准

每个实验冻结配置、负载、代码、成本版本、映射和随机种子；保存清单规范见 docs/interfaces/artifacts.md。只记录 Git commit 不能覆盖未提交代码，应额外保存可恢复补丁与新增文件或源码归档。

架构比较固定负载与数值质量要求。重新映射实验比较各硬件下的可实现方案；固定映射实验保持放置和静态策略，用于归因，同时重新验证合法性。不能把一种实验的结果直接解释成另一种。

校准先分辨误差来自参数、漏建行为还是工作负载差异。训练校准参数与验证模型的数据分离，记录残差、适用域和外推。无校准的面积、能耗、热 RC 结果只能标为条件估计，不能作为物理签核。

搜索结果同时报告可行、失败、取消和未覆盖候选数。随机运行记录重复次数、离散程度与区间方法；确定性运行检验同输入同版本可复现。参数不确定性和随机执行波动分别分析。

## 6 阶段门槛

| 阶段 | 交付重点 | 进入下一阶段的证据 |
| --- | --- | --- |
| A | 架构规范和结构骨架 | 目录、依赖、契约边界、术语和示例可检查；本次交付到此 |
| B | 最小功能闭环 | GEMM/MatVec、独立参考、显式搬运、合法计划与错误诊断 |
| C | 有限资源事件模型 | 单请求、冲突、流水线与重叠均可手算验证 |
| D | 参数扫描和成本比较 | 改一个参数可追溯，固定/重映射分离，结果可复现 |
| E | 异构、封装、节点和集群 | 对应边界的共享瓶颈、通信、精度与容量验证通过 |
| F | 关键路径外部校准 | 实测/工具/可选 RTL 数据、误差报告和适用范围明确 |

阶段 E 可按研究问题与 B–D 局部交错：例如先使用校准摘要 GPU 模型研究集群；这不意味着其内部微架构已通过 C。是否进入更细模型，由结论对未建模行为的敏感程度决定。
