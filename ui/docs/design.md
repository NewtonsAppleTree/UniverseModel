# ui：灵活参数编辑与结果解释

## 核心与边界

最重要的是用户能看清自己改了什么、为什么影响结果。ui 依赖 contracts、configuration、evaluation，读取统一定义生成编辑界面；不得另写一套默认值、派生公式或硬件容量规则。当前是界面设计，没有可运行前端。

`forms` 管 schema 驱动表单，`views/topology` 管物理/连接视图，`package` 管 Die/堆叠/热视图，`mapping` 管任务及数据放置，`timeline` 管执行与等待，`services` 调用配置和实验接口。

## 用户流程与信息结构

选择基线 → 选择物理实例或逻辑视图 → 修改参数草稿 → 查看派生值/约束/影响范围 → 保存方案 → 选择固定映射或重映射 → 运行/扫描 → 比较指标并回溯瓶颈。

| 视图 | 直接操作 | 必须显示的信息 |
| --- | --- | --- |
| 参数表单 | 编辑值、单位、模板或实例覆盖 | 有效值、来源、范围、假设与置信说明 |
| 结构拓扑 | 添加/引用组件、连接端口 | 物理所有者、地址域、协议和共享资源 |
| 封装/堆叠 | 调整 die/stack/link 关系 | 2.5D/3D 局部关系、层数定义与热条件 |
| 参数依赖 | 查看受影响字段与约束 | 输入 → 派生量 → 模型/计划失效链 |
| 映射和时序 | 选择任务、数据或等待区间 | 所属资源、数据位置、前驱和阻塞原因 |
| 方案对比 | 固定基线、过滤、查看 Pareto | 相同指标边界、变更参数、失败/不确定性 |

物理拓扑、通信、放置、热关系使用切换层；不能让一条边同时表示“包含”和“有带宽”。增加 DeviceView 不增加物理面积或容量；UI 应能从视图跳转到唯一物理实例。

## 修改语义与配置灵活性

每次编辑保留草稿 revision，可撤销，提交前显示 diff。模板修改列出所有受影响实例；实例 override 只影响当前实例。派生字段默认只读，选择另一种建模方式时明确切换参数模型。

未知参数显示 unknown 与依赖功能，而非自动补零。模拟 CIM 才显示 ADC/DAC 条件项；数字 CIM、HBF、3D 堆叠分别显示对应约束。高级参数折叠但可搜索；导出的配置足以通过命令行复现。

变更只使相关配置、计划或结果缓存失效；若尚未实现细粒度依赖缓存，可保守失效全部相关产物，不能复用身份不匹配的结果。运行期间修改生成下一份实验配置，已有 run 保持冻结。

## 实施与验证

先实现文本配置/CLI 与相同 schema，再实现表单和 diff，再加入拓扑/依赖图，最后加入映射/时间线与优化视图。这样每层界面都有稳定数据可展示。

验证表单/文本往返、单位转换、条件字段、错误定位、模板影响和运行快照隔离；显示数值必须能追溯到原始指标与单位。界面可缓存读视图，但不持有另一套模型状态。
